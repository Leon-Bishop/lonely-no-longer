# Lonely No Longer — anonymous one-to-one chat

This repository is a **development MVP** for an anonymous, text-only, adult chat service for Ireland. No login, no profiles, no chat rooms: random aliases and one-to-one matching.

**Not safe for public deployment yet.** The age-check provider is a local mock and cannot verify age. The production server intentionally refuses to run with it. Moderation is a prototype and requires significant strengthening, alongside an EU-hosted API and database, before public use.
